關於

MiniHub 是純 HTML / CSS / JavaScript 製作的線上遊戲中心，無需下載，打開就能玩；不保存任何設定或資料，重新開啟網頁即恢復預設。

新增遊戲：把遊戲資料夾放進 games/，再到 js/games.js 加一筆資料即可。

快捷鍵：← → 選擇遊戲、Enter 開始、Esc 離開遊戲。
